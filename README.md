## Getting Started

### Clone the Repository

```bash
git clone https://github.com/NipurnCoder/decodelabs_tasks.git
```

### Navigate to the Repository

```bash
cd decodelabs_tasks
```

### Install Dependencies (if required)

```bash
npm install
```

### Run the Project

```bash
npm start
```

or

```bash
npm run dev
```
